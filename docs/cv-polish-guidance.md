# CV Polish Guidance

Derived notes from local copies of Gergely Orosz's resume/career books. Do not quote or reproduce book text; use these as rewrite heuristics.

## Current CV Target

- Position Sergio as an R&D software engineer for network systems, not as a generic researcher.
- Make PhD work visible as engineering experience: systems, prototypes, simulations, testbeds, publications, research stays.
- Keep academic credibility, but translate papers into software/network impact.
- Preserve public-personal CV tone while making first scan useful for hiring managers.

## Rewrite Rules

- Lead with artifact or outcome, then scope, then technology.
- Prefer strong verbs: `built`, `led`, `designed`, `implemented`, `deployed`, `benchmarked`, `validated`, `maintained`.
- Avoid weak verbs: `worked on`, `participated in`, `helped with`, `responsible for`.
- Keep internal acronyms only when paired with plain-language context.
- Use exact metrics when known: users, nodes, contributors, students, deployments, repositories, packages, latency, throughput, citations, papers.
- Do not invent metrics. If missing, leave phrasing qualitative and add a TODO elsewhere.
- Put key technologies in context inside bullets; keep skills section compact and truthful.

## Sergio-Specific Patterns

- Profile pattern: `R&D software engineer and PhD candidate with 5+ years building software, automation, and testbeds for programmable networks and telecom platforms.`
